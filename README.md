## 🛠️ Tools & Stack yang Digunakan
Proyek ini dibuat 100% gratis tanpa ketikan kode manual (*zero coding*):
* **[MIT App Inventor](https://appinventor.mit.edu/):** Platform visual berbasis drag-and-drop untuk merancang antarmuka dan logika aplikasi.
* **Google Apps Script:** Digunakan untuk pemrosesan logika penerjemahan teks serta menghasilkan output suara Bahasa Jawa yang natural.
* **Google Gemini AI:** Asisten AI untuk membantu pemecahan masalah (troubleshooting) dan menyusun logika blok.

---

## 🧠 Logika Aplikasi (Block Programming)
Aplikasi ini bekerja dengan alur logika sederhana berbasis visual block:

1. **Input:** Pengguna mengucapkan suara dalam Bahasa Indonesia.
2. **Proses:** Aplikasi mengirimkan teks suara ke skrip penerjemah dan pengubah modulasi suara.
3. **Output:** Aplikasi mengeluarkan rekaman suara langsung dalam dialek Bahasa Jawa.
